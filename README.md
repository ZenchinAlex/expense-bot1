# expense-bot

Telegram-бот для учёта общих расходов: записывает траты, определяет категории и показывает отчёты по категориям. Данные хранятся в SQLite. Учебный проект на Python.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | Приветствие |
| `Кофе 150` | Записать расход: название и сумма |
| `/list` | Последние 10 расходов |
| `/stats` | Суммы по категориям и общий итог |
| `/myid` | Показать свой Telegram ID |
| `/partner ID` | Указать партнёра (по его Telegram ID) |
| `/share on` / `/share off` | Разрешить или запретить партнёру видеть свои расходы |
| `/family` | Показать расходы партнёра |
| `/total` | Общая сумма расходов вас и партнёра |


Категория определяется автоматически по названию: «дизель» → машина, «кофе» → еда, неизвестное → другое. Слова для категорий задаются в `categories.py`.

## Как работает общий доступ

Партнёр видит ваши расходы, только если выполнены **оба** условия:
1. Вы оба указали друг друга командой `/partner`.
2. Тот, чьи расходы смотрят, включил `/share on`.

По умолчанию общий доступ выключен.

## Как запустить

1. Создайте бота у @BotFather и получите токен.
2. В папке проекта выполните:
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
3. Создайте файл `.env` с двумя строками:
```
BOT_TOKEN=токен_вашего_бота
ALLOWED_IDS=111111111,222222222
```
4. Запустите бота:
```
python bot.py
```

Токен и база `expenses.db` в репозиторий не попадают (см. `.gitignore`).

## Структура проекта

- `bot.py`: обработчики команд и сообщений;
- `db.py`: работа с базой данных SQLite;
- `categories.py`: определение категории по названию расхода;
- `requirements.txt`: зависимости.



## Запуск через Docker

1. Установите Docker Desktop и убедитесь, что он запущен.
2. Рядом с `docker-compose.yml` создайте файл `.env` с двумя переменными (значения свои):

```
BOT_TOKEN=your-token-here
ALLOWED_IDS=111111111,222222222
```

`BOT_TOKEN` выдаёт @BotFather, `ALLOWED_IDS` — это Telegram ID пользователей, которым разрешён доступ, через запятую.

3. Запустите бота (первый раз образ соберётся сам):

```
docker compose up -d
```

4. После изменений в коде пересоберите образ:

```
docker compose up -d --build
```

5. Остановка:

```
docker compose down
```

Расходы хранятся в томе `expense-data`, поэтому после `docker compose down` и нового запуска они сохраняются.

- Подключил Telegram-бота к базе SQLite: бот разбирает сообщение вроде «Кофе 150», определяет категорию по словарю и сохраняет расход вместе с ID пользователя.
- Хранил токен в `.env` и добавил его в `.gitignore` до первого коммита, чтобы секрет не попал в репозиторий.
- Строил функциональность по шагам: запись расходов, `/list`, `/stats`, категории, затем общий доступ с проверкой двух условий, общий отчёт `/total`, запрет указывать себя партнёром и белый список пользователей. Каждый шаг проверял в Telegram и фиксировал коммитом.
- Упаковал бота в Docker: `Dockerfile` с кэшем слоёв, `.dockerignore`, передача токена через `.env` без копирования в образ, том `expense-data` для базы и запуск одной командой через `docker compose`.
- Научился читать ошибки в терминале и проверять предположения экспериментом: удалял контейнер и смотрел, что происходит с данными.
